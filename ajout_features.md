# Ajout de fonctionnalités

## E-mails transactionnels

- Mail de bienvenue (création de compte)
- Mail pour mot de passe oublié (réinitialisation)

## Visibilité des documents selon le badge / rôle

Chaque document peut être restreint selon le badge (rôle) de l’utilisateur :

- **Tout le monde** — visible sans connexion
- **Contributeurs + admins** — visible uniquement pour les comptes contributeurs et administrateurs
- **Admins uniquement** — visible uniquement pour les administrateurs

## Pièces jointes dans le forum

Système permettant d’ajouter une pièce jointe (fichier) à une réponse du forum.
